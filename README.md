## Installation

1. Clone the repository

   ```bash
   git clone https://github.com/Luckyparihar11/Itsmeluckyparihar.git
   ```

2. Open the project folder

   ```bash
   cd Itsmeluckyparihar
   ```

3. Install dependencies

   ```bash
   npm install
   ```

4. Run the app locally

   ```bash
   npm start
   ```

5. Open in your browser at
   ```bash
   http://localhost:3000
   ```

## Deployment

This project is configured to deploy with GitHub Pages.

```bash
npm run deploy
```
